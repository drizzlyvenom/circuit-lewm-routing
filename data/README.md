# Data Manifests

This folder stores small, versioned manifests and split definitions.

Commit allowed:

```text
data/circuit_sources/source_manifest.json
data/circuit_curricula/train.jsonl
data/circuit_curricula/holdout.jsonl
data/circuit_curricula/test.jsonl
```

Commit forbidden:

```text
data/raw/
data/cache/
data/downloads/
```
