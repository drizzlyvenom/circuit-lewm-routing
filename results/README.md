# Result Summaries

This folder stores small result summaries that can be reviewed and committed.

Commit allowed:

```text
results/qwen/*.json
results/lewm_s/*.json
results/structure_targets/*.json
results/router/*.json
results/certification/*.json
results/system_comparison/*.json
```

Commit forbidden:

```text
results/tmp/
results/cache/
large raw output dumps
checkpoints
tensor dumps
```
